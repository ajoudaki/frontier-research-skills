Hacky tactics, not a silver bullet

I started using ChatGPT back in 2022, mostly for coding, and coding has improved enormously. Research is different, because research fails differently. When code is wrong, you usually see it: it doesn't run, a test fails, the plot looks off. When research is wrong, it can fail miserably and still look fine. So as the models got smarter, using that intelligence for research actually got harder. At some point I gave up and went back to pen and paper. Part of it is control. We used to do everything ourselves, so we knew exactly what was going on. Now so much is delegated that it's easy to lose track. What follows is how I got that control back. It's not a silver bullet, just simple hacks that made a big difference.
