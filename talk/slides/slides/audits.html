What a careful scientist does, delegated.

The most effective tool I've found is fresh, independent auditors, and this is where subagents come in. Asking the same thread to be unbiased doesn't work. A thread that's been celebrating keeps giving you happy feedback, and a thread that's turned negative stays negative. So you don't ask for independence; you enforce it mechanically. You spawn a new agent, so it doesn't carry the long thread. But fresh isn't enough: if it can read your earlier notes saying "this is a great result", it's biased all over again. So I give it a folder with only the files it should see, and keep everything else outside. Then I use several of these, each from one angle. One re-derives the math. One checks or tests the code. One checks the literature, and whether citations are used correctly. And one asks: are we still answering the original question? It's what a careful scientist would do, just delegated. Two skills in the repo do this. review-ai-paper does it for papers: it reads the whole paper, pulls the cited sources to check they really say what's claimed, audits the code, and builds a claim ledger before writing the review. And organize-research-project writes the isolation rule down.
