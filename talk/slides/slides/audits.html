What a careful scientist does, delegated.

Once something is solved, you need to check it, and this is where subagents come in. Asking the same thread to be unbiased doesn't work. A thread that's been celebrating keeps giving you happy feedback, and a thread that's turned negative stays negative. So you don't ask for independence; you enforce it mechanically. You spawn a new agent, so it doesn't carry the long thread. But fresh isn't enough: if it can read your earlier notes saying "this is a great result", it's biased all over again. So each auditor gets a folder with only the files it should see. Then I use several, each from one angle: one re-derives the math, one tests the code or reruns the experiment, one checks the literature and whether citations are used correctly, and one asks whether we're still answering the original question. It's what a careful scientist would do, just delegated. In the repo, review-ai-paper does this for research papers, mine or anyone else's: it pulls the cited sources to check they really say what's claimed, audits the code, and builds a claim ledger before writing the review. And organize-research-project writes the isolation rule down.
