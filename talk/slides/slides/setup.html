02 · The basics

Most of the value is in the basics.

Not my invention. It's the 80/20: just learn these.

A coding agent, not a chat

Codex or Claude Code inside your repo: papers, code and results already in context.

One always-on machine

Everything in one place. Connect from anywhere; agents work overnight.

Skills

Instructions the agent loads only when a task needs them.

AGENTS.md / CLAUDE.md

Project rules, read at the start of every session.

Routing

Reference files opened only when needed.

Subagents

Fresh agents with a clean context. More on the next slide.

It starts with some very basic techniques. None of this slide is my invention, but these simple things make a tremendous difference: the perfect 80/20. Two matter most. First, leave the chat interface and use a coding agent that runs directly in your repo. Then the theory, the LaTeX, the code, even the results and figures are all in context, and you stop uploading things back and forth. Second, run everything on one always-on machine, a central workstation where everything lives. Agents can work overnight and wait for runs to finish, and even if you dispatch jobs elsewhere, everything comes back to one place. Then a few more basics many researchers don't use: skills; AGENTS.md or CLAUDE.md, which every agent reads, so you don't repeat your prompts; routing, so a large skill is split into files and nothing unnecessary gets loaded; and subagents, which come next.
