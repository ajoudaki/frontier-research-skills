02 · Setup

Leave the chat window. Centralize.

Run agents locally

Codex or Claude Code, next to your papers, code and notes. The context is always there.

One always-on machine

Connect from anywhere, send out compute from it, and let agents work overnight.

repo › handoff-codex-project-tasks

First, two basic things. One: stop using the chat window. In a chat you have to re-upload your papers and code every time. A coding agent like Codex or Claude Code sits on top of your repo, so the theory, the code, the results and the figures are all already in context, even when the work is pure theory. Two: don't run it on your laptop. Run it on a workstation that's always on, and connect to it from wherever you are. That gives you one central place where everything lives, instead of pieces scattered across chat threads. It can still send heavy jobs to other machines and collect the results. And because it never sleeps, the agents can work overnight and wait for long runs.
