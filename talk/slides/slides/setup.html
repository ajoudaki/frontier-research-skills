First, the basics, because I didn't know some of these existed until recently, and you might not either. One: stop using the chat window. A coding agent like Codex or Claude Code runs inside your repo, so your papers, code, results and figures are already in context. You never re-upload anything. Two: run it on a workstation that's always on, and connect to it from anywhere. Everything lives in one place, heavy jobs can still go out to other machines, and the agents can work overnight or wait for long runs to finish. Then there are the pieces you configure. A skill is a folder with a SKILL.md file. The agent only sees its short description, and loads the full instructions when a task needs them, or when you call it by name. AGENTS.md, or CLAUDE.md for Claude Code, holds the project's rules, and it's read at the start of every session, so keep it short. A skill can also route: it links reference files that are opened only when needed, so the agent loads the one hundred-page paper it needs, not all ten. And finally, subagents: the main agent can spawn fresh agents with a clean context. Each does one job and reports back to it. That last one turns out to be the key to most of what follows.
