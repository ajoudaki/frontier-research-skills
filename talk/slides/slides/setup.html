None of this next part is my invention, and that's exactly the point. These models are very smart, and it's still easy to have a horrible experience, simply because you don't know what's possible. This slide is the 80/20, most of the value comes from these basics. The two big ones. First, leave the chat window: a coding agent like Codex or Claude Code runs inside your repo, so your papers, code and results are already in context, and you never re-upload anything. Second, run everything on one always-on machine you connect to from anywhere: one place where everything lives, and agents that keep working overnight. Then four things worth reading up on. Skills: folders with a SKILL.md file that the agent loads only when a task needs them. AGENTS.md, or CLAUDE.md for Claude Code: the project's rules, read at the start of every session. Routing: a skill can link reference files that are opened only when needed, so out of ten long papers, the agent loads only the one it needs. And subagents: fresh agents that the main agent spawns, each with a clean context. That last one deserves its own slide.
