For those who want more detail, let's take a closer look at each of the five skills, in the order you'd use them. For a single question, it starts with formulate-problem, which turns a vague question into a precise one. Then solve-problem solves it, and every step gets checked. Then teach-material makes sure you actually understand the result. A whole project is many such questions: develop-project runs them as separate studies and grows a core of results you can trust. And when it's time for a paper, review-paper audits it, and its findings can start the next round. Let's start with formulate.
