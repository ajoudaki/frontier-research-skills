(Already recorded, no need to redo.) One more thing: on big open questions, these agents don't have much foresight. You ask for a summary and they start running new experiments. So I keep them on a short leash. Every task gets an explicit permission level: read-only, theory, experiment design, or actually running compute. It also gets a hard budget and a point where it stops. And experiments are pre-registered: we decide what counts as a pass, fail, or inconclusive before running, so nobody moves the goalposts after the experiment is done.
