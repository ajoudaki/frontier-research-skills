You can simply ask the main thread to start agents. What makes it practical are three foundations. Context: a coding agent, not a chat, on one always-on workstation. Then the theory, the LaTeX, the code, the results and the figures are all in reach. Agents work overnight, and even if you dispatch jobs elsewhere, the results come back. Persistence: everything under version control, and everything in the same place, theory included. Every snapshot holds the theory, the code, the audits and the paper together, so when an agent's refactor goes wrong, or you change your mind, you roll all of it back. Reuse. A project is just a folder with a file every agent in it reads, so the project's rules load by default. Prompts you type again and again become skills, which load by name or when a task matches them, and they're plain files, so they move with you to another model.
